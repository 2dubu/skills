# Repository instructions

This repository contains personal agent skills.

- Keep each skill in `skills/<skill-name>/`; the folder name and frontmatter `name` must match.
- Update the README skill catalog when adding, removing, or renaming a skill.
- Keep supporting scripts, references, and assets inside the skill that needs them. Use relative links.
- Preserve bundled copyright notices and license terms when editing imported material.
- Keep changes focused on the requested workflow. Preserve existing invocation metadata unless changing it is part of the request.
- Validate YAML metadata and referenced local files after edits. Run relevant checks for changed scripts or assets.
