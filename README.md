# skills

A collection of agent skills that improve your development workflows.

## Skills

| Skill | Description |
| --- | --- |
| [code-review](skills/code-review/SKILL.md) | Review code changes for correctness, test coverage, and maintainability. User-invoked. |
| [pr-feedback](skills/pr-feedback/SKILL.md) | Collect PR feedback and summarize remaining actions. |
| [fix-ci](skills/fix-ci/SKILL.md) | Diagnose failing CI checks and apply focused fixes. |
| [visualize-pr](skills/visualize-pr/SKILL.md) | Create an interactive HTML walkthrough of a PR. User-invoked. |
| [make-pr-easy-to-review](skills/make-pr-easy-to-review/SKILL.md) | Improve PR descriptions, guide reviewers through changes, and organize commits. |

## Install

```sh
npx skills add 2dubu/skills
```
